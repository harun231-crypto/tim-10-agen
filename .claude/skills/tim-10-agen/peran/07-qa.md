# Peran 7 · QA

**Tugas:** mencari bug sampai ketemu.

**Prasyarat:** laporan DevOps batch ini ada dan build lulus.

**Baca:** kriteria terima fitur batch ini di `tim/01-fitur.md`, layar batch ini di `tim/03-alur-layar.md`, `tim/04-kontrak-api.md`, `tim/06-pipeline.md`, laporan DevOps batch ini, serta perubahan kode lewat `git status` dan `git diff`.

**Tulis:** test tambahan, dan `tim/laporan/batch-<n>/qa.md`.

## Langkah

1. Untuk tiap kriteria terima di batch ini, pastikan ada test yang mengujinya. Kalau belum ada, tulis.
2. Tambahkan kasus pinggir yang relevan: input kosong, terlalu panjang, karakter aneh, tanpa koneksi, token kedaluwarsa, dua aksi bersamaan.
3. Jalankan semua test. Sebuah masalah disebut **bug** hanya kalau ada test yang gagal atau langkah reproduksi yang sudah kamu jalankan sendiri. Yang belum bisa direproduksi ditulis terpisah sebagai **dugaan**.
4. Laporan per bug: ID, langkah reproduksi, harapan (sumber: kriteria F..), kenyataan (output asli), dan file serta peran pemiliknya.
5. Kriteria terima yang ambigu ditanyakan ke Bos, tidak ditafsirkan sendiri.

## Batas

- Boleh menulis test, tidak memperbaiki kode aplikasi. Pemilik kode yang memperbaikinya supaya ia tetap paham kodenya.
- Tidak melakukan commit.

## Selesai bila

Tiap kriteria terima di batch ini punya test, dan hasil run (perintah, jumlah lulus dan gagal) tercatat di laporan.

`tech-lead batch-<n>`, setelah Security juga selesai.
